## 🚀 Getting Started

### Prerequisites

- Node.js 18 or later
- npm, pnpm, or yarn

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/nosij-playz/jisonsebastian.git
cd jisonsebastian
npm install
```

### Environment Configuration

If the project includes an `.env.example` file, copy it and configure the required environment variables:

```bash
cp .env.example .env
```

Add the necessary API credentials to `.env`. Never commit secrets, API keys, or private credentials to the repository.

### Run the Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
