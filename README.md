## 🚀 Getting Started

### Prerequisites
- Node.js 18+ & npm / pnpm / yarn

### Installation
```bash
git clone https://github.com/nosij-playz/jisonsebastian.git
cd jisonsebastian
npm install
```

### Environment Configuration
Copy the `.env.example` file and provide your API credentials:
```bash
cp .env.example .env
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
